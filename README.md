# Глубина / Undergrid

Планировщик подземных баз для Minecraft: вид сверху по блокам, этажи по Y, разрез сбоку, экспорт в Litematica.
Языки: русский, English, Português (BR).

## Структура

```
index.html            разметка всех страниц (лендинг, «Мои планы», редактор, диалоги)
favicon.svg
src/
  main.js             логика приложения
  i18n.js             переводы: $t(), множественное число, перевод статичной разметки
  brand.js            название проекта по языкам — меняется здесь
  geometry.js         геометрия комнат: прямоугольники, круги, многоугольники, стены, площади
  lib/nbt.js          запись NBT и gzip для .litematic
  locales/en.js       английский словарь
  locales/pt.js       португальский (Бразилия)
  style.css
```

Сборка не нужна: браузер грузит модули напрямую. Но открыть `index.html` двойным кликом не получится,
модулям нужен сервер. Локально запусти в папке проекта:

```
python3 -m http.server 8000
```

и открой http://localhost:8000.

## Как устроены переводы

Ключ перевода — русский текст. В коде это `$t('Мои планы')`, с подстановкой —
`$t('Изменён {date}', {date})`. Тексты из `index.html` переводятся сами: при запуске
скрипт запоминает все русские строки и атрибуты (title, aria-label, placeholder) и подменяет их.

Новый язык: скопируй `src/locales/en.js`, переведи значения, подключи файл в `src/i18n.js`
(`DICTS`, `LANGS`, `LOCALE`, `PLURALS`) и добавь `<option>` в три переключателя `select.lang` в `index.html`.
Если перевода для строки нет, показывается русский текст, а строка попадает в `window.__i18n.missing`.

## Название

`src/brand.js`: русское имя «Глубина», международное пока рабочее — Undergrid. Поменяешь там,
и оно сменится на сайте, в заголовках и в именах скачиваемых файлов.
