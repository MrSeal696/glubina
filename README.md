# Глубина

Бесплатный планировщик подземных баз для Minecraft. Рисуешь базу видом сверху, где одна клетка равна одному блоку, раскладываешь залы по этажам и строишь по готовым координатам.

**Открыть:** https://ИМЯ.github.io/glubina/ <!-- замени ИМЯ на свой ник на GitHub -->

## Что умеет

- Сетка в блоках и настоящие границы чанков 16×16 твоего мира
- Этажи по высоте Y: толщина пола и высота помещения для одного этажа или всех сразу, автоматический расчёт Y или ручная настройка, соседний этаж просвечивает пунктиром
- Разрез сбоку с любой из четырёх сторон: линия разреза двигается по мини-плану, сквозные атриумы и шахты склеиваются по этажам
- Привязка к координатам мира: углы любой комнаты и команда /tp в один клик
- Прямоугольные комнаты и круглые залы с нечётным диаметром
- Стены заданной толщины, внутренний размер считается сам
- Цветные типы помещений: жильё, склады, фермы, авто-фермы, ивенты, техника
- Копирование и вставка, копия на все этажи, автонумерация названий
- Несколько планов, шаблоны для старта
- Экспорт в Litematica (`.litematic`): стены, полы и воздух внутри комнат, регионы строго по контурам помещений, координаты Origin для точной установки в мире
- Блоки стен и полов для всего проекта, этажа или отдельной комнаты
- Экспорт: файл плана `.json`, картинка этажа или разреза `.png`, список комнат текстом

## Где хранятся планы

В браузере (localStorage) на устройстве пользователя. Сервер не нужен, данные никуда не отправляются. Для бэкапа и переноса на другое устройство план скачивается файлом `.json` и загружается обратно через «Импорт».

## Где выложить

Весь сайт живёт в одном файле `index.html` без сборки и зависимостей. Шрифты подгружаются с Google Fonts в фоне: если они недоступны, сайт открывается с системным шрифтом.

### SourceCraft Sites (открывается из России)

1. Зарегистрируйся на [sourcecraft.dev](https://sourcecraft.dev) и создай **публичную** организацию.
2. Создай в ней **публичный** пустой репозиторий, например `glubina`.
3. Загрузи в корень ветки `main` файлы `index.html`, `README.md` и папку `.sourcecraft` с файлом `sites.yaml`.
4. Через несколько минут сайт будет по адресу `https://ОРГАНИЗАЦИЯ.sourcecraft.site/glubina`.

### Netlify или GitHub Pages (для остального мира)

- Netlify: перетащи папку на [app.netlify.com/drop](https://app.netlify.com/drop).
- GitHub Pages: загрузи файлы в публичный репозиторий, затем Settings → Pages → Deploy from a branch, `main`, `/ (root)`.

Из России эти хостинги часто не открываются, поэтому для русскоязычных игроков лучше давать ссылку на SourceCraft.

### Без хостинга

Файл `index.html` можно просто отправить другу: он откроет его двойным кликом в браузере, и всё будет работать. Планы сохранятся в его браузере.

## Формат файла плана

```json
{
  "format": "underground-plan/1",
  "project": "Название",
  "origin_world": { "x": 0, "z": 0 },
  "floors": [
    {
      "name": "Ярус 1", "y_floor": 48, "floor_thickness": 1, "height": 14,
      "rooms": [
        { "name": "Склад 1", "type": "storage", "shape": "rect",
          "x_from": 7, "x_to": 34, "z_from": -60, "z_to": -37,
          "wall": 1, "height": 14, "notes": "" }
      ]
    }
  ]
}
```

Координаты считаются от центрального блока (0, 0) и включают стены. X растёт на восток, Z на юг, как в игре. `y_floor` — Y нижнего блока плиты пола, `stand_y = y_floor + floor_thickness` — Y, на котором стоишь, `height` — высота внутри без пола, `ceiling_y` — последний блок воздуха под потолком.
